## change (6436b003)
- sender ack-stall: an RTO's loss recovery no longer closes at once; the link must show bytes_acked frozen with data in
  flight for max(1 s, 8 x srtt) like the plain path (ackStallRTONow=false; the older tests set it true to keep their
  timelines). TestAckStallRTONeedsFrozen: RTO + 600 ms frozen -> no close; link moves -> window restarts;
  unacked=0 -> no close; closes at >= 1 s frozen. In the lab the RTO closes now show frozen=1.008..1.913 s.
