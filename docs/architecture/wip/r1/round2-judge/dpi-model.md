# مدل رفتاری DPI با شمار واقعی اتصال‌ها

`python3 tools/dpi_count.py <hs2-src/obfs/dpi_eval2.py> <real_sizes>`: خانوادهٔ B `obfs/dpi_eval2.py` (رفتاری، میان‌اتصالی) با شمار اتصالی که هر باینری برای استخری با `max_links`=N باز می‌کند. AUC ۰٫۵ یعنی سکه و ۱٫۰ یعنی آشکار. «همهٔ نشانه‌ها» یعنی سه نشانهٔ دیگر `dpi_eval2` (پخش برقراری، نظم keepalive، عمر) با مقدارهای «پس از سخت‌سازی» خود آن ابزار و شمار ثابت.

| N (max_links) | اتصال پایه / β1 / β2 | AUC تک‌نشانهٔ شمار اتصال: پایه / β1 / β2 | AUC همهٔ نشانه‌ها: پایه / β1 / β2 |
|---|---|---|---|
| 1 | 1 / 2 / 2 | 0.948 / 0.787 / 0.787 | 0.999 / 0.994 / 0.994 |
| 2 | 2 / 4 / 2 | 0.787 / 0.695 / 0.787 | 0.994 / 0.997 / 0.994 |
| 4 | 4 / 8 / 4 | 0.695 / 1.000 / 0.695 | 0.997 / 1.000 / 0.997 |
| 8 | 8 / 16 / 8 | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |
| 16 | 16 / 32 / 16 | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |
| 64 | 64 / 128 / 64 | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |
| 300 | 300 / 600 / 300 | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |

نامزد نهایی (QUIET بیرون از `max_links`): ۳ اتصال در `N=2`: تک‌نشانه ۰٫۵۴۷، همه ۰٫۹۹۴؛ ۶ اتصال در `N=4`: ۰٫۹۴۸، همه ۱٫۰۰۰ (`tools/dpi_count2.py`). از `N=8`، ۱۰ اتصال: ۱٫۰۰۰.
