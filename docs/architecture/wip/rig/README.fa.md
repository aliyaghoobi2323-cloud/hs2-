# چیدمان سنجش Z5 (رونوشت از پوشهٔ موقت نشست ابری، ۱۷ مهر)

این پوشه منبع چیدمان آزمایشگاهی سنجش پنجره است که دور دوم Z5 با آن سنجیده شد (نسخهٔ طرح «کاوش»، با سناریوی تغییر سرعت در میانهٔ انتقال: `Z5_DN_SCHED` و `Z5_UP_SCHED`). این فایل‌ها بیرون ماژول `hs2-src` هستند و در ساخت شرکت نمی‌کنند.

- `z5emu_test.go`: شبیه‌ساز مسیر روی TUN (نرخ، تأخیر، صف دم‌ریز، اتلاف) با TCP واقعی هسته و BBR.
- `z5rig_test.go` (`TestZ5Rig`): یک انتقال تند یا چند جریان روی لینک‌های uTLS واقعی، با کاربر تعاملی کنار آن؛ خروجی یک سطر JSON.
- `z5lm_test.go` (`TestZ5LM`): پشتهٔ کامل لبه با LinkManager و RunKharej واقعی.
- `z5knobs_*_test.go`: دستگیره‌های مخصوص هر نسخه (N4 و کاوش).
- `build.sh TREE NAME [need] [trial]`: فایل‌های چیدمان را موقتاً در `TREE/engine` می‌گذارد و `bin/NAME.test` را می‌سازد.
- `run1.sh BIN ENV=V...`: یک اجرا در فضای نام شبکهٔ جدا با بافرهای TCP پروفایل «high».
- `mkplan.py` و `runplan.sh`: ساخت و اجرای برنامهٔ اجراهای یکی‌درمیان (قابل ادامه پس از قطع).
- `summ.py`، `table.py`، `losswin.py`، `lmsum.py`، `cpusum.py`، `status.sh`: خلاصه و جدول.
- `compat/`: برنامهٔ سازگاری با فرستنده و گیرندهٔ upstream v1.5.24 و `c9825f2` (پوشه‌های `old` و `up` که منبع آن نسخه‌ها بودند ذخیره نشده‌اند).
- `cpubench/`: محک پردازندهٔ خود smux روی loopback.

نیاز: دسترسی root (برای `unshare -n` و TUN) و Go همان نسخهٔ `hs2-src/go.mod`.
