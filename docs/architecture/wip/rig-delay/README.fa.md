# چیدمان سنجش طرح «تأخیر صف» (رونوشت از پوشهٔ موقت نشست ابری، ۱۸ مهر)

همان چیدمان `../rig/` است با این افزوده‌ها:
- تغییر سرعت در میانهٔ انتقال با `Z5_CHG_*` (در `z5emu_test.go` و `z5rig_test.go`)؛
- ضبط سطرهای حکم «ضعیف» در `z5lm_test.go`؛
- `mkplan3.py` (برنامهٔ اجراهای یکی‌درمیان) و `sumall.py` (جدول همهٔ معیارها)؛
- درنگ کوتاه پیش از هر اجرا وقتی بار دستگاه بالای ۸ است.

`plaintest/`: برنامهٔ بازتولید یک ایستادن گاه‌به‌گاه در دانلود ۹۶MiB روی یک جفت smux سادهٔ loopback، که با smux بالادستی v1.5.24 هم دیده شد.
